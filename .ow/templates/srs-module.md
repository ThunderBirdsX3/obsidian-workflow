### FR-100 — Librarian checks out a book to a Member

- **Priority**: P1
- **Source user story**: US1 (PRD-<slug>)
- **Description**: the system must let a Librarian record a Member's loan of 1 Book in a single action, with default due_date = today + 14 calendar days
- **Inputs**: `member_id` (UUID), `book_id` (UUID), `librarian_id` (from the session)
- **Outputs**: `loan_id` (UUID) + `due_date` (ISO 8601)
- **Pre-conditions**:
  - the Member must be `status = active`
  - the Book must be `status = available`
  - the Member has fewer than 5 active loans (business rule)
- **Post-conditions**:
  - Loan record `status = open`
  - Book `status = borrowed`
  - an audit log entry is created
- **Acceptance** (Given/When/Then):
  1. **Given** the Member has 2 active loans + Book A is available, **When** the Librarian checks out Book A to the Member, **Then** the system creates the loan + shows due_date + flips Book A to borrowed
  2. **Given** the Member has 5 active loans, **When** the Librarian checks out Book A, **Then** the system rejects it with the error "loan limit exceeded"
- **Error handling**: 409 Conflict on a race condition (2 librarians checking out the same copy) — enforced by a DB unique constraint on `(book_id, status=open)`
- **Dependencies**: FR-900 (Auth), FR-200 (Catalog read)

### FR-101 — Librarian records a return

- **Priority**: P1
- **Source user story**: US1
- **Description**: the system must close an open loan when the Book comes back and make the Book available again
- **Inputs**: `book_id` (UUID, from the barcode scan)
- **Outputs**: `loan_id` + `returned_at` + `days_overdue` (0 when on time)
- **Pre-conditions**: the Book has exactly one loan with `status = open`
- **Post-conditions**: Loan `status = closed`, Book `status = available`, an audit log entry is created
- **Acceptance**:
  1. **Given** Book A is on an open loan, **When** the Librarian scans Book A at return, **Then** the loan closes + Book A becomes available + `days_overdue` is shown
  2. **Given** Book A has no open loan, **When** it is scanned at return, **Then** the system shows "no open loan for this book" and changes nothing
- **Dependencies**: FR-100
